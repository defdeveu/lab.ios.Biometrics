# Run the exercise

1. From the repository root, open the project:

   ```sh
   open lab.ios.Biometrics.xcodeproj
   ```

2. In Xcode, select the `lab.ios.Biometrics` scheme.
3. Select a Face ID-capable iPhone Simulator running iOS 17 or newer.
4. Run the app with `⌘R`.
5. In Simulator, choose **Features → Face ID → Enrolled**.
6. Trigger the biometric prompt in the app, then choose
   **Features → Face ID → Matching Face**.
7. Run the included tests with `⌘U`.
